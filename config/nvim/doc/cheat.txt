NOW                                                              *cheat-now*

Practising these. Move a line to its section once it's a reflex.

  :grep {pat}      search into the quickfix list               |:grep|
  ]q  [q           next / previous quickfix entry              |]q|
  :copen           open the quickfix window                    |:copen|
  gO               outline of the file or man page             |gO|
  `"               back to where I last left this file         |'quote|
  `0               back to where I last quit Neovim            |'0|
  :oldfiles        recently opened files                       |:oldfiles|

GREP AND QUICKFIX                                               *cheat-grep*

  :grep {pat}      default 'grepprg' is "rg --vimgrep -uu"     |'grepprg'|
                   -uu skips .gitignore, so ignored files match too
  :cdo {cmd}       run {cmd} on every quickfix entry           |:cdo|
  :Cfilter {pat}   keep matching entries (:packadd cfilter)    |:Cfilter|

==============================================================================
LSP                                                              *cheat-lsp*

  CTRL-]  CTRL-T   go to definition / back                     |lsp-defaults|
  K                hover docs
  grr  gri         references / implementations
  grn  gra         rename / code action
  [d  ]d           previous / next diagnostic                  |]d|
  CTRL-W d         diagnostic under the cursor in a float      |CTRL-W_d|
  :checkhealth vim.lsp   enabled configs and attached clients  |:checkhealth|
  :lua =vim.lsp.get_clients()   which servers are running
  :e               re-read the buffer, attaches a newly enabled server
                   sh/bash: bashls runs shellcheck; zsh: no LSP, use zsh -n

==============================================================================
MERGE CONFLICTS                                                *cheat-merge*

  ]x  [x           next / previous conflict marker (conflict.lua)
  git mergetool    each conflicted file in Neovim, git add on :wq
  <<< ||| === >>>  ours | base | theirs (zdiff3 in gitconfig)
                   in a rebase, ours is the branch I'm rebasing onto
  git checkout --conflict=zdiff3 {file}   redo the markers from scratch
  git add {file}   mark resolved; UU in git status clears only then
  :grep '^[<=>|]{7}( |$)'   every marker in the repo, into quickfix

==============================================================================
MAN PAGES                                                        *cheat-man*

  man {name}       opens in Neovim ($MANPAGER is set in zshrc)
  :Man {name}      open a man page in a split                  |:Man|
  K  CTRL-]        open the page under the cursor
  CTRL-T           back to the previous page
  gO               outline of the page's sections

==============================================================================
GIT HUNKS                                                        *cheat-git*

  ]g  [g           next / previous hunk (gitsigns)
  \hp              preview hunk
  \hb              blame for the current line in a float, full message
  \tb              toggle blame as virtual text at end of line
  \hs  \hr         stage / reset hunk, also in visual mode

==============================================================================
LATER                                                          *cheat-later*

  :Undotree        browse undo history (:packadd nvim.undotree) |:Undotree|
  :DiffTool {a} {b}  diff two dirs or files (:packadd nvim.difftool)
  :restart         restart Neovim, keeping the session         |:restart|
  v an  v in       grow / shrink selection by syntax node      |v_an|
